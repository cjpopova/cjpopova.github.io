# Caspar's website

## Install
```bash
# Install Ruby 
gem install jekyll bundler 
bundle init
bundle add jekyll
bundle install
bundle exec jekyll serve
```

Instructions for setting up jekyll and all:
https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/adding-content-to-your-github-pages-site-using-jekyll#about-content-in-jekyll-sites

Instructions for customizing the sidebar: https://github.com/orderedlist/minimal/issues/29

**Run your Jekyll site locally: `bundle exec jekyll serve`**
